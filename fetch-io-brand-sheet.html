// 08_non_negotiable

Rules

Toolbars wrap. No control bar ever scrolls horizontally, at any width.
Mono runs ~12% wider than a proportional face. Every table is re-checked at 1280px; if columns crowd, hide columns rather than shrinking type below 13px.
Passwords are masked everywhere, revealed only on explicit click, never in localStorage, never in the console.
Every mutation: optimistic update → toast → rollback on error. Every destructive one: a confirm naming the count, written as a plain sentence.
One locale setting drives every date and every number in the app. No component formats anything itself, and no component sets a font family.
